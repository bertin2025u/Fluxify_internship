# Personal Project Proposal

## Project Title
Student Task Manager

## Problem Statement
Many students forget assignments and daily responsibilities because they do not organize their tasks properly.

## Proposed Solution
Build a simple and responsive task management web application where students can add, complete, filter, and delete tasks.

## Main Features
1. Add new tasks
2. Mark tasks as completed
3. Delete tasks
4. Filter tasks by status
5. Save tasks using Local Storage

## Technologies
- HTML
- CSS
- JavaScript

## Target Users
Students and beginners who need a lightweight productivity tool.

## Expected Outcome
A fully functional and responsive web application that helps students manage tasks efficiently.
