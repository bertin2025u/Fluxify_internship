# Student Task Manager

## Project Description
Student Task Manager is a responsive web application that helps students organize their daily tasks and assignments.

## Features
- Add tasks
- Mark tasks as completed
- Delete tasks
- Filter tasks (All, Completed, Pending)
- Saves tasks using Local Storage
- Responsive design for mobile and desktop

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Target Users
Students who want a simple way to manage tasks and assignments.

## How to Run the Project
1. Download the project files
2. Open the folder
3. Open index.html in your browser
